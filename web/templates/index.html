导出 / 导入媒体库

导出把整个库（数据库 + 封面 + 截图 + 磁力文本档）打成压缩包， 用于备份或搬到另一台机器。导入是合并： 同番号不重复建、同路径不重复加，导入前会自动备份现有库。

素材通常占大头（实测截图 276MB vs 数据库 1.5MB）。 只要库和元数据时可以不勾。

导入：选一个本工具导出的 .zip（或上传），合并进当前库。

清理低分卡片

按当前识别规则重新算分，列出 ≤ 阈值 的库内条目。 清理是只从库里摘除记录，磁盘文件不动； 真要删文件请用卡片上的「删除」按钮（那条路有磁力门控 + 回收站）。

0 分要特别注意：那是当前规则已经识别不出的条目 —— 多半是早期规则宽松时入库的假阳性（把英文词、分辨率、发布方合集标当成了番号）。 规则收紧后它们重放不出结果，是最该清的一批。 70 分则是「厂牌未收录」的低置信猜测，里面可能混着真番号， 建议先看下面的分布和列表再决定。
